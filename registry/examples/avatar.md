# Avatar examples

Initials on the brand gradient or a neutral disc, in three sizes.

```tsx
import { Avatar } from "@/components/ui";

<Avatar name="Jane Cooper" />
```

## Sizes and tones

```tsx
<Avatar name="Jane Cooper" size="sm" />
<Avatar name="Wade Warren" />
<Avatar name="Esther Howard" size="lg" tone="neutral" />
```

Docs: https://rime.mjsons.net/components/avatar
