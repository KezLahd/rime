# Spinner examples

A small brand-tinted spinner for in-flight work inside buttons, fields and panels.

```tsx
import { Spinner } from "@/components/ui";

<Spinner label="Loading invoices" />
```

## Sizes

```tsx
<Spinner size={14} />
<Spinner size={20} label="Loading" />
```

Docs: https://rime.mjsons.net/components/spinner
