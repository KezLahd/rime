# GlassPanel examples

Frosted glass over the page field: page, light and nested variants, padding steps and an optional bloom.

```tsx
import { GlassPanel } from "@/components/ui";

<GlassPanel padding="lg">…</GlassPanel>
```

## Variants

```tsx
<GlassPanel>Page</GlassPanel>
<GlassPanel variant="light">Light</GlassPanel>
<GlassPanel variant="nested" padding="sm">Nested</GlassPanel>
<GlassPanel bloom>With bloom</GlassPanel>
```

Docs: https://rime.mjsons.net/components/glass-panel
